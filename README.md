# 🐾 PawsHappy - Website de PetShop

Um website moderno e responsivo para um petshop, desenvolvido com HTML5, CSS3 e JavaScript vanilla.

## ✨ Características

- **Design Moderno**: Layout limpo e elegante com gradientes e animações suaves
- **Responsivo**: Funciona perfeitamente em desktop, tablet e mobile
- **Seções Completas**:
  - Hero section com chamada à ação
  - Serviços oferecidos
  - Produtos em destaque
  - Informações sobre a empresa
  - Formulário de contato
  - Footer com links rápidos

- **Animações Fluidas**:
  - Scroll suave para navegação
  - Efeitos hover nos cards
  - Animações de entrada ao carregar
  - Ícones animados

- **Interatividade**:
  - Menu responsivo com hamburger
  - Formulário funcional de contato
  - Carrinho de compras interativo
  - Links de navegação com destaque ativo

## 🎨 Paleta de Cores

- Primária: `#FF6B6B` (Coral)
- Secundária: `#4ECDC4` (Turquesa)
- Escura: `#2C3E50` (Azul Escuro)
- Clara: `#ECF0F1` (Cinza Claro)

## 📱 Responsividade

O site é totalmente responsivo com breakpoints otimizados para:
- Desktop (1200px+)
- Tablet (768px - 1199px)
- Mobile (<768px)

## 🚀 Como Usar

1. Clone o repositório
2. Abra o arquivo `index.html` no seu navegador
3. Ou faça deploy em um servidor web (GitHub Pages, Netlify, etc)

## 📁 Estrutura
